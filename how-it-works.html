Pipeline

From Upload
to Verdict

Your document flows through a rigorous, transparent pipeline. Every step produces traceable evidence — no black-box decisions.

01

Upload

Drag and drop your PDF or DOCX file. We validate the file type and size, store the original securely, and create a submission record. Your document is queued for processing instantly.

PDF DOCX TXT Max 50MB
02

Preprocessing

Text is extracted (with OCR fallback for scanned PDFs), cleaned, normalized, and segmented into sentences with stable IDs. Raw metadata — timestamps, author, producer — is captured separately for manipulation analysis.

pdfplumber OCR fallback Unicode normalize
03

Parallel Analysis

Four independent modules run simultaneously: plagiarism n-gram matching, AI content classification, metadata manipulation checks, and semantic similarity search. Each produces its own sub-score and flagged segments.

Plagiarism
AI Detection
Manipulation
Similarity
04

Scoring Engine

Sub-scores are combined using configurable, institution-adjustable weights into a single authenticity score (0–100). Threshold bands assign a human-readable status — never a binary pass/fail.

Clean (80–100)
Review (50–79)
Flagged (0–49)
05

Report Generation

A comprehensive report is generated: the hero score gauge, per-module breakdown cards with expandable evidence, and an inline text viewer with highlighted flagged segments linked to matched sources. Exportable as PDF.

Score Gauge Evidence Cards PDF Export

Average processing time

~8 seconds

For a standard 10-page document. Longer documents process proportionally. Real-time progress updates keep you informed throughout.
