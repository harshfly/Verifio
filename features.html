Modules

Four Engines.
One Verdict.

Each module is an independent detection pipeline producing its own sub-score and flagged evidence. Combined, they give you a comprehensive authenticity report.

Plagiarism Detection

N-gram overlap analysis against a growing corpus of academic submissions. Identifies verbatim and near-exact copy-paste with source attribution.

  • Exact & near-exact matching
  • Source reference tracking
  • Sentence-level granularity
Sub-score 92/100

AI Content Detection

Dual-signal analysis using a fine-tuned RoBERTa classifier and perplexity/burstiness heuristics to identify machine-generated paragraphs.

  • RoBERTa-based classification
  • Perplexity & burstiness analysis
  • Paragraph-level flagging
Sub-score 87/100

Manipulation Analysis

Deep inspection of file metadata — timestamps, author fields, producer software, revision counts, and PDF object-level font inconsistencies.

  • Metadata anomaly detection
  • Timestamp consistency checks
  • Font & structure analysis
Sub-score 95/100

Semantic Similarity

Sentence-transformer embeddings with cosine similarity search across the entire submission corpus. Catches paraphrased content that n-grams miss.

  • Paraphrase-level detection
  • Vector similarity search
  • Confidence scoring
Sub-score 89/100

Weighted Scoring

Configurable module weights that combine into a single authenticity score with clean/review/flagged bands.

PDF Export

Generate detailed, shareable PDF reports with all evidence, scores, and flagged segments for institutional records.

Role-Based Access

Three access tiers — student, evaluator, admin — ensuring sensitive reports stay with authorized users only.

Async Processing

Dark Mode

Built from day one with CSS variables. Switch seamlessly between light and dark themes across every view.

Fully Responsive

Every page, every component — optimized for desktop, tablet, and mobile with adaptive layouts.
